## 📊 ABSTRACT

**Target Journal**: npj Digital Medicine
**Word Count**: 250 words (journal limit)

### Abstract

**Background**: EEG biomarkers show promise for neurological disorders but lack reproducible, regulatory-aligned validation frameworks. Current pipelines produce static results, limiting clinical and regulatory translation.

**Objective**: To present the first automated, self-monitoring platform for multi-site EEG biomarker validation that integrates real-time quality monitoring, traffic-light performance signaling, and live manuscript updating.

**Methods**: The platform combines a locked Core5 biomarker pipeline with CORAL domain adaptation to address cross-site variability. Automation features include: (i) dynamic badge system for threshold-based QC alerts, (ii) auto-updating manuscripts synchronised with results, and (iii) enhanced dashboards with supervisor-ready summaries. Governance is ensured via audit logs, locked parameters, and Data Safety Monitoring Board (DSMB) oversight.

**Results**: Two independent Parkinson's disease datasets (UCSD, Iowa) were validated using Leave-One-Site-Out (LOSO). The framework achieved a mean balanced accuracy of 65.5% (≥65% clinical threshold), with processing efficiency of 0.37s per subject. Badges, manuscripts, and dashboards updated automatically with each validation run.

**Conclusions**: This self-monitoring framework reduces validation time by ~70% compared with conventional workflows and delivers reproducible, regulatory-compliant outputs. By transforming static pipelines into dynamic infrastructures, it establishes a reference standard for digital health validation and enables adoption by clinical researchers, regulators, and industry.

**Keywords**: EEG biomarkers, validation infrastructure, real-time monitoring, regulatory compliance, domain adaptation, automation, reproducibility, digital health
