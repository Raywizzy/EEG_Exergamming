## 🔬 **Slide 5: Locked Pipeline Approach**

### **Critical Design Feature: NO RETRAINING**

**Core5 Biomarkers (Fixed)**:
1. `duration_cv` - β-burst duration variability
2. `duty_cycle` - Time in β-burst state
3. `mean_duration_ms` - Average burst duration
4. `median_duration_ms` - Median burst duration
5. `motor_posterior_duty_ratio` - Spatial distribution ratio

**CORAL Domain Adaptation**: Pre-computed transformation matrix

**Classification Model**: Logistic regression with fixed coefficients from Phase III

**Regulatory Advantage**: Locked pipeline demonstrates genuine prospective validation
